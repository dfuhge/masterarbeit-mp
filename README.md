# Prozedurale Eigenschaften musikdidaktischer Konzepte. Eine Analyse von Fachzeitschriftartikeln.


Dies ist das Repository für die Daten und Auswertungen im Rahmen der Masterarbeit "Prozedurale Eigenschaften musikdidaktischer Konzepte. Eine Analyse von Fachzeitschriftartikeln."
Das Repository besteht aus 4 Dateien:
- analysen.ipynb: Code für die Analysen
- Schritte_final.csv: Kompletter Datensatz
- Schritte_final_ohneDoppel.csv: Kompletter Datensatz mit aufgelösten Mehrfachannotationen (wie in der Arbeit beschrieben)
- KI-Prompts.pdf: Alle für die Arbeit verwendeten KI-Prompts zur Dokumentation
